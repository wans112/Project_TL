# DOS2-Subtitle-Translator

DOS2-Subtitle-Translator adalah sebuah proyek open-source untuk menerjemahkan subtitle pada game **Divinity: Original Sin 2**. Proyek ini bertujuan memudahkan proses translasi, pengelolaan, dan integrasi subtitle hasil terjemahan ke dalam game, sehingga pemain dapat menikmati pengalaman bermain dengan teks berbahasa Indonesia atau bahasa lain sesuai kebutuhan.

## Fitur

- Ekstraksi subtitle dari file game Divinity: Original Sin 2
- Mendukung proses penerjemahan subtitle secara batch
- Penyimpanan dan pengelolaan hasil terjemahan
- Integrasi subtitle terjemahan kembali ke dalam format game

## Cara Pemakaian

1. **Klon Repository**
   ```bash
   git clone https://github.com/wans112/Project_TL.git
   cd Project_TL
   ```

2. **(Opsional) Membuat Virtual Environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   ```

3. **Instalasi Dependency**
   Jika tersedia file `requirements.txt`, jalankan:
   ```bash
   pip install -r requirements.txt
   ```
   Jika belum ada, pastikan install library yang diperlukan sesuai kebutuhan project.

4. **Menjalankan Proyek**
   Jalankan file utama (misal: `main.py` atau sesuai file utama yang tersedia):
   ```bash
   python main.py
   ```
   *Pastikan mengganti `main.py` dengan nama file utama dari proyek ini.*

5. **Mulai Proses Penerjemahan**
   - Ikuti petunjuk pada aplikasi/CLI untuk mengekstrak subtitle, menerjemahkan, dan mengintegrasikan hasil terjemahan ke dalam game.
